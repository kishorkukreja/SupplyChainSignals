Operator guide

How to use the clock-triage model

Pick a live equipment book, approximate the current order values, then use the readout to decide which orders need premium freight, classification work, supplier evidence, split shipment, repricing or a pause.

1

Keep stations separate

Drewry is a lane-price station. LMI is a diffusion-cost station. NRF/Hackett is an import forecast. USTR and Section 232 are policy clocks.

2

Edit current facts

Change margin, days to ship, receiving capacity, evidence quality and clock pressures. The simulator treats weak proof as a cost risk before duty cash is paid.

3

Choose a mode

Baseline uses W26 pressure. Proof before premium favors evidence work. Pay for time raises freight urgency. Air pocket penalizes excess inventory and weak demand proof.

4

Read the owner

The top clock is the function that should own the next meeting: logistics, trade, warehouse, finance or commercial.

5

Act on exceptions

High scores mean the order needs an explicit go/wait/split/reclassify/reprice decision before the booking window closes.

6

Use traceable facts

The default reference cards come from W26 newsletter notes because the Signal Translation folder was absent after the required retry window.
